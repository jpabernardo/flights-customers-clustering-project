# Multi-Perspective Clustering for Airline Loyalty Programs

This repository contains the code and report for the Data Mining project
developed as part of the Master in Data Science and Advanced Analytics
at NOVA IMS.

## Project Overview
The goal of this project is to identify actionable customer segments for
an airline loyalty program using multiple clustering techniques:
- K-Means
- Hierarchical Clustering
- Self-Organizing Maps (SOM)

Two complementary perspectives are explored:
- Customer Value & Loyalty Engagement (CVLE)
- Travel Behavior (TB)
